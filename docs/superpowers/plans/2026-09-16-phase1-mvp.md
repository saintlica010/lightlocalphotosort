# Phase 1 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a focused local-first Windows PySide6 app that can create/open a project, scan images without modifying them, browse a thumbnail grid, preview, maintain independently ordered virtual lists, reject/restore, and undo those curation actions.

**Architecture:** Thin `sqlite3` persistence with `PRAGMA user_version` migrations; domain models and services own behavior; Qt widgets never talk to SQL directly. Thumbnails and project state live in the project directory, never beside source media.

**Tech Stack:** Python 3.12+ (this machine has 3.14.3), PySide6, stdlib `sqlite3`, Pillow, pytest, pytest-qt, PyInstaller later.

## Global Constraints

- Primary OS: Windows 10/11; package name `local_media_curator` under `src/`.
- Local-first, offline, no telemetry, no cloud, no AI, no face recognition, no SQLAlchemy, no Alembic.
- Never modify, rename, move, or delete source media; never write EXIF/XMP; never create caches inside source folders.
- Protected local directories must never be committed or used as test output: `photos/`, `phototakeplan/`, `lightphotosprt/`.
- Automated tests use generated fixtures in pytest temp dirs, never `photos/`.
- Schema uses `list_items.sort_key INTEGER` (sparse integers: 1024, 2048, …), not a position on `media`.
- Enable SQLite foreign keys. Ordering lives on the list–media relationship.
- Git: never `git add .`; stage explicit paths; author is `lica.liu`.
- Do not fork TagStudio; do not copy GPL TagStudio code.
- Keep UI / services / db / media processing separated as in AGENTS.md §13.

```python
from __future__ import annotations

import sqlite3
from pathlib import Path


def connect(db_path: Path) -> sqlite3.Connection:
    db_path.parent.mkdir(parents=True, exist_ok=True)
    conn = sqlite3.connect(db_path)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA foreign_keys = ON")
    conn.execute("PRAGMA busy_timeout = 5000")
    return conn
```

```sql
    name TEXT NOT NULL UNIQUE,
    description TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);

CREATE TABLE list_items (
    list_id INTEGER NOT NULL,
    media_id INTEGER NOT NULL,
    sort_key INTEGER NOT NULL,
    added_at TEXT NOT NULL,
    PRIMARY KEY (list_id, media_id),
    FOREIGN KEY (list_id) REFERENCES lists(id) ON DELETE CASCADE,
    FOREIGN KEY (media_id) REFERENCES media(id) ON DELETE CASCADE
);

CREATE TABLE source_folders (
    id INTEGER PRIMARY KEY,
    path TEXT NOT NULL UNIQUE,
    recursive INTEGER NOT NULL DEFAULT 1,
```

```python
from local_media_curator.services.library_service import LibraryService
```
